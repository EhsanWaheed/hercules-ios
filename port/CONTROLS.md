# Hercules Recompiled: controls

## In the game

| Keyboard | Gamepad | PlayStation |
|----------|---------|-------------|
| Arrow keys | D-pad / left stick | D-pad |
| X | A (Cross) | ✕ |
| S | B (Circle) | ○ |
| Z | X (Square) | □ |
| A | Y (Triangle) | △ |
| Q / W | LB / RB | L1 / R1 |
| E / R | LT / RT | L2 / R2 |
| Enter | Start | Start |
| Right Shift | Back / Select | Select |

The keyboard keys can be changed in the menu (Esc), page **Keys**: choose a
button, press Enter, then the new key (Esc cancels). "Restore defaults" puts
them back. They are kept in `keybinds.ini` next to the game.

## Menu and shortcuts

| Keyboard | Gamepad | What |
|----------|---------|------|
| **Esc** | **Select + Start** | **Menu**: pauses the game. Resume, back to the launcher, graphics (HD characters / scenery / HUD, texture filter, 16:9 or 4:3, window or fullscreen, perspective, geometry), filters (CRT picture, mask, glow, scanlines, colours), volume, the keyboard keys, and this list. Changes apply at once and are kept. |
| F7 | Select + R1 | Save states: 12 slots with pictures (S save, L or Enter load) |
| F8 | Select + R3 | Rewind |
| Tab (hold) | Select + L1 (hold) | Fast forward |
| F9 | – | Fast forward on / off |
| F6 | – | Scanlines (and the CRT picture) on / off |
| Alt + Enter or Ctrl + F | – | Fullscreen |
| Numpad + / − | – | Volume |
| F | – | Frames per second in the window title |
| F3 / F4 | – | Statistics / texture inspector (for debugging) |
| F5 (with F4 on) | – | Freeze the picture: wheel or Tab steps through the objects under the mouse, a click marks one (saved to `texture_marks.txt`), F5 or Esc goes on |

In the menu: Up/Down choose a line, Left/Right change it (on the top line:
change the page), Enter or ✕ select, Esc or △ / ○ / Start close.

## Launcher

Arrow keys or gamepad, Enter / ✕ to choose, Esc / △ back, F11 fullscreen;
the mouse works too.
